🚀 Ship It

Mode 3 — getting animations into the real app: loading, testing, releasing (for adults) · 模式三：把动画装进真正的应用——加载、测试、发布（给大人）

The kids made something great in animation-studio/output/. This guide is how it reaches the actual pet on the desktop. There are two paths, and knowing which one you need saves you an hour:

孩子们在 output/ 里做出了好东西。这份指南教你把它装到桌面上真正的宠物身上。有两条路，选对路能省一小时：

Best for 适合New creature families; quick experiments 新物种、快速试玩Permanently improving the default Clawd 永久改进默认 Clawd
Needs a release? 需要发版？No — instant 不需要，立即生效Yes: version bump + tag + publish 需要：升版本+打标签+发布

Path A — Load as a user theme (no release needed)

1

Find the user themes folder 找到用户主题文件夹

Windows:  %APPDATA%\clawd-on-desk\themes\
macOS:    ~/Library/Application Support/clawd-on-desk/themes/
Linux:    ~/.config/clawd-on-desk/themes/

Create it if it doesn't exist, then make a subfolder per theme, e.g. themes/rect-bird/.

2

Assemble the theme 组装主题

Inside rect-bird/: a theme.json plus an assets/ folder containing the SVGs. The repo ships a fully commented scaffold at themes/template/theme.json — start from it. A minimal working example:

{
  "schemaVersion": 1,
  "name": "Rect-Bird",
  "author": "Your kid's name here",
  "version": "1.0.0",
  "viewBox": { "x": -15, "y": -25, "width": 45, "height": 45 },
  "sleepSequence": { "mode": "direct" },
  "states": {
    "idle":     ["pip-idle.svg"],
    "thinking": ["pip-thinking.svg"],
    "working":  ["pip-working.svg"]
  }
}

Only three states are mandatory: idle, thinking, working (see src/theme-schema.js). Every other state is optional and falls back gracefully. "sleepSequence": {"mode": "direct"} avoids needing the four sleep-transition animations. Add more states as the kids produce them — juggling is the one the dance feature uses.

只有三个状态是必需的：idle（发呆）、thinking（思考）、working（工作）。其他都可省略。direct 睡眠模式可以免掉四个睡觉过渡动画。孩子做出新动画就往里加——跳舞功能用的是 juggling 状态。

3

Activate 启用

Restart the app → tray menu → Settings → Theme → your theme is listed. Switch to it and the pet transforms.

重启应用 → 托盘菜单 → 设置 → 主题 → 选择你的主题，宠物立刻变身。

Path B — Bake into the built-in Clawd theme (released)

1

Add the file to the repo 把文件放进仓库

Copy the SVG into assets/svg/, keeping the clawd-*.svg naming.

2

Map it to a state 映射到状态

In themes/clawd/theme.json, find "states" and either replace an existing file or append yours to the array (the app can rotate among several). Example — a new dance for the activity-dance feature:

"juggling": ["clawd-headphones-groove.svg", "clawd-dance-party.svg"]

Scope note: mapping files to existing states is config-only. Inventing a brand-new state (e.g. "singing") requires app code — that's a developer task, not covered here.

在 themes/clawd/theme.json 的 states 里替换或追加文件名。注意：只有映射到现有状态是纯配置；发明全新状态需要改代码，不在本指南范围。

3

Release 发布

The installed app updates from GitHub Releases of this fork — never from branches. The runbook:

  1. Bump "version" in package.json (e.g. 0.11.0 → 0.11.1). Mandatory — the updater only acts on a higher version.
  2. Create docs/releases/release-v0.11.1.md with the release notes. Mandatory — CI reads exactly this path and fails without it.
  3. Commit to main, then: 
    git tag v0.11.1 && git push origin main v0.11.1
  4. GitHub Actions (.github/workflows/build.yml) builds Windows/macOS/Linux installers and creates a draft release.
  5. Go to the repo's Releases page and Publish the draft. Drafts are invisible to the updater.
  6. Installed apps pick it up on the next scheduled check, or immediately via tray → Check for Updates.

发布六步：① 升 package.json 版本号（必须）② 写 docs/releases/release-v版本号.md（必须，CI 读这个路径）③ 提交并推送标签 ④ CI 自动构建三平台安装包并创建草稿发布 ⑤ 到 Releases 页面点 Publish——草稿对更新器不可见 ⑥ 已安装的应用会自动发现更新。

🧪 Testing before you ship 上线前测试

  1. Browser pass: double-click the SVG. Full loop, no jump at the loop point, nothing clipped, still on-model.
  2. Live app pass: from a repo clone run npm install && npm start.
    • idle: hands off the mouse and wait.
    • working/thinking: start a real Claude Code session in a hooked terminal — or temporarily map your file to idle for instant viewing, then map it back.
    • Dance tiers (this fork's feature): launch with 
      CLAWD_ACTIVITY_DANCE_FORCE_TIER=2 npm start
      to pin the dance regardless of real keyboard activity (1=groove, 2=party, 0=off). Also make sure "Dance with Me" is ticked in the tray menu.
  3. Size pass: in Settings try the smallest and largest pet size — small sizes eat pixel details; confirm the silhouette still reads.

三道测试：① 浏览器双击看整圈循环 ② 从代码仓库 npm start 真机测试（想立即看到可临时映射到 idle；跳舞用 CLAWD_ACTIVITY_DANCE_FORCE_TIER=2 强制触发，并确认托盘菜单勾选了“陪我跳舞”）③ 在设置里试最大和最小尺寸，确认轮廓依然清晰。

🩹 Troubleshooting 排查

Symptom 症状Cause & fix 原因与解决
App says no update found 应用说没有更新 Version not bumped, or the release is still a draft. 版本号没升，或发布还是草稿。
CI release job failed CI 发布失败 Missing docs/releases/release-v<version>.md. 缺少发布说明文件。
macOS won't auto-install update macOS 不自动更新 Unsigned builds can't auto-install on macOS — download the .dmg from the Releases page manually. 未签名的构建在 macOS 上不能自动安装，需手动下载。
Theme doesn't appear in Settings 主题没出现 Wrong folder path, or theme.json invalid / missing one of idle/working/thinking. 文件夹路径不对，或 theme.json 无效、缺少三个必需状态。
Animation frozen in the app 动画在应用里不动 Low-power idle mode may pause animations; also verify the SVG uses CSS keyframes, not SMIL. 可能是低功耗模式暂停了动画；并确认 SVG 用的是 CSS 关键帧而不是 SMIL。
